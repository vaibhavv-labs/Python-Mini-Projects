# 🐍 Python Mini Projects

A collection of beginner-friendly Python mini projects built to practice core programming concepts.

---

## 📁 Projects

| Project | Description |
|---|---|
| `Mini_ATM.py` | Simulates an ATM — check balance, withdraw, and deposit |
| `OTP_Verifcation.py` | Generates a 6-digit OTP and verifies user input |
| `QR_Code_genrator.py` | Takes a URL and generates a QR code image |
| `calender_project.py` | Displays a monthly calendar for any given year |
| `password_generator.py` | Generates a random alphanumeric password |
| `simple_calculater.py` | Basic calculator for +, −, ×, ÷ operations |

---

## 🚀 How to Run

```bash
python <filename>.py
```

**Dependencies** (install once):
```bash
pip install qrcode[pil]
```
> All other projects use Python's built-in libraries only.

---

## 🛠️ Tech Used

- Python 3.x
- Libraries: `random`, `string`, `calendar`, `qrcode`
